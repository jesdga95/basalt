# 0.3.2

2026-11-08. Taken from `main`. Build from source: [building](../building.md), or take a release archive ([platforms](../platforms.md#release-archives)). No flag changes; the `.basalt` format stays version 2.

## Highlights

- DeepSeek decodes faster. Cold, seed 42, RAM tier 316, 400 W + 180 W, `basalt-bench` ABBA, 0.3.1's `main` against this release: struct 154 to 178 tok/s, prose 88 to 96, conversation 81 to 94 (conversation's text changes with the promotion margin below, so its windows do not compare one to one).
- Release archives for Linux x64 and Windows x64 come with each release. They hold no CUDA libraries: the CUDA 13 toolkit's runtime and an R580 or newer driver are required. [platforms](../platforms.md#release-archives)
- The binary finds its data, `serve/` and `.venv` next to its own `bin/` folder, not at the source path baked in at build time, so an install can be moved.
- The second card's share of a layer reads its activations and plan from mapped memory, so it no longer waits behind a slot swap's copies on the card's copy engines. First expert kernel after the ids, with a slot copy in flight: 81.4 to 41.8 us.

## DeepSeek decode

All bitwise the same output (greedy identical on frozen tiers) except the promotion margin.

- **The second card's exchanges** go out in pieces in the bus's idle time.
- **Down rows of 72 calls** take eight lanes, four rows a warp.
- **Gate/up pairs of 5120 values** take two rows a warp, IQ1_S among them, and three entries a pass at three blocks an SM.
- **The exact CPU expert rows** (IQ1_S, IQ2_XXS, IQ2_XS, IQ1_M) decode a block once for up to four tokens: 3 tokens, 1 thread, per row 0.54 to 0.29 us for IQ1_S, 0.51 to 0.21 for IQ2_XXS.
- **Short windows' sparse MQA** takes 8 heads a block.
- **The drafter's kernels:** Q6_K short rows stage their columns once per block, `wo_a` takes Q8_0 weights, and the experts take four rows a warp.
- **The expert pool:** a down part waiting for its expert's intermediate prefetches its own rows into L2 (down phase 64.2 to 60.4 us in a trace), and a layer's last parts are a quarter of the others.
- **Promotion to the second card** needs its victim to be 1,280 lookups (about 32 windows) older than the main card's, so more promotions take a main card slot. This one moves which experts the CPU computes, so the rounding moves. BF16 gate, 100 chunks: KLD 0.27971 to 0.27944 (paired -0.00027, 95% CI -0.00199 to +0.00144), top-1 83.89% to 83.77%: within noise. [precision](../precision/deepseek41.md)

## Release archives and install

- `basalt-vX.Y.Z-linux-x64.tar.gz` and `basalt-vX.Y.Z-windows-x64.zip` are attached to each GitHub Release: `bin/`, `serve/`, `data/`, `docs/` and what the server imports. `tools/package_release.py` packs a built tree.
- `bin/basalt serve` uses the `.venv` at the archive's top directory when it is there. The build-time source path (`BASALT_SOURCE_DIR`) is gone: the install root is the directory above the executable's own.
