# 0.5.6

2026-11-21. Taken from `main`. Build from source: [building](../building.md), or take a release archive ([platforms](../platforms.md#release-archives)). A patch release for Inkling 2 Mini: faster decode with the same output, and prompt-lookup drafts. The `.basalt` format stays version 2 and the config stays version 2.

## Highlights

- **Faster Inkling 2 Mini decode, bit for bit the same output.** On an RTX 5090 alone at 400 W, `basalt-bench -r 2` (A B B A against 0.5.5): conversation 338 to 347 tok/s (+2.6 %), struct 616 to 628 (+1.9 %), prose 288 to 296 (+2.9 %). A 16K prompt reads at 12,310 tok/s, as before.
- **Prompt lookup drafts.** `--suffix-draft` (default 3) now works for Inkling 2 Mini: when the context repeats an earlier stretch, a window takes the copied tokens if the draft policy expects more from them than from the DSpark block. A 2,405-token copy prompt decodes 13 % faster; prompts without repeats are unchanged.

## Inkling 2 Mini

- A 3-row window runs the fused window attention too, and its blocks prepare up to three window rows from one round of loads.
- A 5 to 8-row window's loop controllers take two outputs a down-projection block instead of four.
- `moe_plan` scans the experts' counts with every warp at once; the mix's softmax takes a state a lane and runs once a block; the decode glue's block sums shuffle less.
- `post_attn`, `mix_norm` and `ctrl_blend` read before their wait what no earlier kernel writes; the attention's older key/value cells are requested into L2 before the wait; the fused attention's slices are handed over with a shared-memory release and acquire.
- The drafter head's final pick reads a quarter of the scores (the same list), about 5 us a draft.

## Upgrading

- No flag or config key is removed or renamed. The `.basalt` format stays version 2 and the config version stays 2.

## Checked

At 400 W, against 0.5.5 (`main`, ff0b978d2), Inkling 2 Mini:

- Kernel, drafter and prompt parity tests pass; windows of 1 to 8 rows give the same greedy tokens as 0.5.5; drafted output equals `--spec 1` on conversation, struct and prose after short and 16K prompts, in the CLI and through `--serve`, and on a copy prompt through `--serve`.
- Mean KLD of 20 chunks against the BF16 base 0.00264, top-1 97.80 %, as before.
- Every model built with warnings as errors; CPU tests (104), GPU tests (148, those needing absent packs skipped), serve tests and the repository checks pass.
