# 0.2.0

2026-11-01. Taken from `main`. Build from source: [building](../building.md). This release changes the `.basalt` file format: read [Upgrading](#upgrading) first.

## Highlights

- `.basalt` file format version 2. The engine requires a version 2 pack and refuses a version 1 pack with a message naming `tools/migrations/basalt_v1_to_v2.py`. The weights are the same and the output is identical. Version 2 packs are on Hugging Face; a version 1 pack you already have can be migrated locally, with no download and no re-quantizing. The expert profile now ships with the engine (`data/profiles`), and the int8 hyper-connection table is stored in the pack, so a start skips about 0.5 s of work. [file changelog](../basalt-file-changelog.md), [model file](../model-file.md)
- Decode speed, cold, RTX 5090 at 400 W with an RTX 5060 Ti at 180 W, NVFP4 pack, against `main` as of 0.1.0: about +13%. Prose alone 297 to about 330-337 tok/s; the full bench order prose 277 to about 296 tok/s; struct 558 to about 600 tok/s. All of it is exact: greedy output is identical. The levers:
  - a cheaper draft-head scan: the draft head screens its rows through a 2-bit copy and reads its exact rows from the main head;
  - an exact two-stage output head: the Q8_0 head runs in bit planes and keeps the exact top K for the requests that read only the top of the list, [two-stage head](../precision/two-stage-head.md);
  - the head screen shared with the second card, when it is slower than the main card;
  - a better starting expert placement, learned from varied prompts;
  - adaptation rounds that rank earlier, once the window's last layer is served, and promote experts routed about once lately when swaps are to spare;
  - the QSA gate rows run beside the attention.
- Lossy opt-in flags: `--route-prior`, `--route-tail-skip` and `--relaxed-drafting` change the output. They are off by default, never picked automatically, and a start with any of them on prints a warning. Quality and decode numbers on three packs: [routing](../precision/routing.md).
- Thinking-loop safeguard: a run that repeats one token 256 times in a row inside the thinking ends the thinking, and the model answers. Answers are never watched. `thinking-loop-tokens` sets the count, `0` turns it off. [sampling](../configuration/sampling.md#thinking-loops)

## Upgrading

1. Rebuild: [building](../building.md).
2. Get a version 2 pack: download it from Hugging Face, or migrate the version 1 pack you have with `python tools/migrations/basalt_v1_to_v2.py` ([migrations](../../tools/migrations/README.md)).
3. Removed, with no alias: the engine's `--dump-hc8`, and the converter's `--profile`, `--profile-from` and `--hc8` (the profile is the engine's, the hyper-connection table is computed by the converter). A converter run writes version 2 files. The server's `repeat_stop_tokens` setting and its "length" stop on a repeated token are gone, and so is the thinking budget's invented wrap-up sentence.
4. A sampling value out of range is now a 400 (see Changed).

## Recent

Changes from 2026-10-29 to 2026-11-01.

### New

- The two-stage output head, bit-plane Q8_0 head and shared head screen above; [two-stage head](../precision/two-stage-head.md).
- `--route-prior`, `--route-tail-skip`; relaxed drafting joins the lossy-flags start warning. [routing](../precision/routing.md)
- `thinking-loop-tokens`.
- The web UI is up while the model loads and shows the load percent and each card's GiB; a request that arrives while the model loads waits for it, and a failed start-up load answers it with a 503.
- Idle conversations leave VRAM once the work beside them has run 15 s, so a cache that was taken by an idle slot goes back to experts; they restore into whichever slot comes next.
- The address and the APIs print once at listen, a weights line after each load.
- Penalties apply in batch windows.
- `basalt-probe` tries the adaptive-tier settings from one engine and a saved profile, and its report gives the run's wall time.
- A vision sidecar runs on a card that is not sm_120 and builds on its own (@Yunado).
- Windows: a second card works as an expert tier (@hagudelom).

### Faster

Decode numbers are in Highlights; the rest are commit-level and not benchmark results.

- MTP: the round's K/V append runs beside its draft row's query projection; the draft head starts with its final mixer read; the proxy draft head keeps its rescored rows in a fixed order (@xyehya).
- Verify: the PLE side branch forks after layer 0's mid chain; batch windows run the whole head on CUDA0 beside a split two-stage head.
- Adapt: with one peer card the main card's rounds rank every layer together; a round promotes at most 16 once-routed CPU-tier experts.
- A prompt loan beside decoding slots moves an expert an earlier loan still holds from its RAM copy.
- The CPU pool: a parked worker yields its core after the short spin, only when the pool's threads outnumber the physical cores.
- Startup: the expert cache fill has no pipeline bubbles (@jmgao).
- The prompt split runs with KV streaming.
- Drafting: the draft head's context rows keep the latest missing tokens of a long prompt and take the target's candidates the subset lacks; batch draft stores keep only the cells the drafter reads.

### Changed

- Sampling values reach the sampler as sent; a value out of range is a 400 naming it (it was clamped or dropped). `top_k` 0 and -1 mean no limit, above 64 samples the list asked for; `penalty_last_n` is 0 to 4096; a seed of 0 is a seed. Sampling defaults come from the model file's GGUF metadata.
- The thinking budget ends the thinking with the template's own close; `answer-room` stays on by default.
- A reply that repeats one token is no longer ended by the server; "length" means `max_tokens`.
- An engine failure is a 500, not a 400. An image request whose prompt is longer than the context is refused before its positions are set.
- The RAM guard sheds parked conversations and waits when RAM is low, and stops a request only when RAM is critical (@xyehya).
- The VRAM reserve floor is 128 MiB on Linux, and a batched server keeps room for what loads after the cache (@xyehya).
- A stored conversation keeps its system prompt and last three turn states; the solo conversation keeps its draft K/V through a request in another slot.
- Parallel tool results are ordered by call id (@giveen); generation starts at prompt position zero (@giveen).
- Adaptive swaps a request queued, and those deferred for want of a free RAM place, are logged (@xyehya).
- The benchmark check refuses a submitter name with spaces.

### Fixed

- Bounded device waits set an abort word instead of trapping the kernel.
- The elastic KV maps on the floor's grid, so a deep request's cells go back; the KV arena's grid is at least a page (@xyehya).
- Windows: a path past MAX_PATH opens (@hagudelom); the n-gram table reader and `DirectFile` read a file mapped elsewhere (@f1zz1ec0ke).
- A vision card nvidia-smi cannot name is reported as not found by it; a prompt the split declines always says why.
- Uninitialized surrogate code units in the grammar's hex parse.
- Compiler warnings in the engine and the tests are cleared; `WERROR` covers nvcc, and CI builds Linux with it.
