# 0.3.1

Unreleased. Fixes to 0.3.0; the config and `.basalt` formats stay as they are.

- **Experts on the SSD are said everywhere.** Any expert only the file holds gives one engine warning, the same for every
  model: `N experts on SSD (X GiB) · free X GiB RAM`, plus the model's other fixes where it has them, such as `--gpu 0,1`.
  The server console repeats it, `/metrics` carries `engine.spill` (`experts`, `total`, `bytes`; `null` when nothing
  spilled) and each request's `ssd_share`, and the stats page turns its Experts block amber with an SSD tier.
  [memory floors](../running.md#memory-floors)
- **One RAM reserve for every model.** `--ram-reserve-mib` (default 2048) is the RAM left free for the rest of the system; the
  old floors (5% of RAM, fixed late memory, the file cache minimum, DeepSeek's fixed 16 GiB) are gone. DeepSeek allocates its
  prompt and image host buffers at start and its RAM tier takes the rest less the reserve and the driver's page tracking, so
  one place short no longer sends about 12 more experts per layer to the file. Its prompt ring of second-card and file reads
  is capped instead of growing with the experts left in the file, and a prompt no longer stages a whole chunk's embeddings
  and Engram rows. Flash-Next allocates its checkpoint blocks and holds the RAM of its page-locked prompt buffers before its
  RAM copy, which then sizes the same way; its estimate of what it takes later is gone. [memory floors](../running.md#memory-floors)
- **One RAM guard for every model.** The serving RAM guard starts in the shared serve path and holds the reserve, so DeepSeek
  now sheds parked conversations, holds new requests and stops one at critical RAM as Flash-Next does. `--ram-reserve-mib 0`
  turns it off, for machines where it stopped requests that would have fit (reported by @pngen).
  [memory floors](../running.md#memory-floors)
- **Default context 8,192 for every model.** Flash-Next's was 4,096 and DeepSeek's the pack's maximum lowered to fit
  memory; `--max-context` still sets it. [models](../models/index.md)
- **Start lines.** Each model's line shows the drafting the engine will run (`spec=N`); a shared idle sleep is said once, on
  the shared line; the conversation folder line shows only with `--debug`; a load reads `loading MODEL (N waiting)` and a swap
  `swap OLD -> NEW (N waiting)`.
- **`--max-payload-mib` sets the largest request body.** The server reads up to 256 MiB by default; a bigger body gets a 413
  naming the limit. [configuration](../configuration/index.md)
