# 0.3.1

Unreleased. Fixes to 0.3.0; the config and `.basalt` formats stay as they are.

- **Experts on the SSD are said everywhere.** Any expert only the file holds gives one engine warning, the same for every
  model: `N experts on SSD (X GiB) · free X GiB RAM`, plus the model's other fixes where it has them, such as `--gpu 0,1`.
  The server console repeats it, `/metrics` carries `engine.spill` (`experts`, `total`, `bytes`; `null` when nothing
  spilled) and each request's `ssd_share`, and the stats page turns its Experts block amber with an SSD tier.
  [memory floors](../running.md#memory-floors)
- **DeepSeek RAM floor without a cliff.** The RAM tier always leaves 16 GiB free; one place short no longer raised the
  floor to 20 GiB and sent about 12 more experts per layer to the file. [DeepSeek](../models/deepseek41.md)
- **One RAM guard for every model.** The serving RAM guard starts in the shared serve path, so DeepSeek now sheds
  parked conversations, holds new requests and stops one at critical RAM as Flash-Next does. `--no-ram-guard` turns it
  off for any model, for machines where it stopped requests that would have fit (reported by @pngen).
  [memory floors](../running.md#memory-floors)
- **Default context 8,192 for every model.** Flash-Next's was 4,096 and DeepSeek's the pack's maximum lowered to fit
  memory; `--max-context` still sets it. [models](../models/index.md)
- **Start lines.** Each model's line shows the drafting the engine will run (`spec=N`); a shared idle sleep is said once, on
  the shared line; the conversation folder line shows only with `--debug`; a load reads `loading MODEL (N waiting)` and a swap
  `swap OLD -> NEW (N waiting)`.
