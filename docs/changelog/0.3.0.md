# 0.3.0

2026-11-05. Build from source: [building](../building.md). The config format changes, so read [Upgrading](#upgrading) first. The `.basalt` format stays version 2.

## Highlights

- Basalt is multi model. DeepSeek-V4.1-Flash runs on the same engine, server, bench and probe as Qwen3.8-Flash-Next, and each model's code lives in its own folder. Flash-Next's output is unchanged: [what was checked](#checked).
- A router: a config lists several models, a request's `model` field picks one, and one is loaded at a time. Clients wait through a swap; a wrong name is a 404 and a failed load a 503 naming the model, and the server stays up. [models and the router](../configuration/models.md)
- DeepSeek-V4.1-Flash is first class: [what it supports and does not](#deepseek-v41-flash).

## Upgrading

1. Rebuild: [building](../building.md). The Linux build needs GCC 13 or newer.
2. **The config format changes.** A config without `models` is refused at start: `Basalt requires v2 config, please upgrade`. `python3 tools/migrations/config_v1_to_v2.py basalt_config.json -o basalt_config.v2.json` writes the new shape; the old file is only read. [models and the router](../configuration/models.md)
3. `.basalt` files keep working as they are.
4. Open pull requests need a rebase: most of `src/core`, `src/prefill`, `src/kernels` and `src/program` moved. Model code is under `src/models/<model>` and `include/basalt/models/<model>`, and server dialects under `serve/models`. To add a model: [adding a model](../adding-a-model.md).

## DeepSeek-V4.1-Flash

The pack is `DeepSeek-V4.1-Flash-1017-UD-IQ1_M.basalt` on [Hugging Face](https://huggingface.co/jesdga/DeepSeek-V4.1-Flash-1017-Basalt), built from Unsloth's UD-IQ1_M GGUF (Dynamic V3.1, @unsloth) with `convert.py --sections-from`. [DeepSeek-V4.1](../models/deepseek41.md)

- **Supported:** chat on every API, thinking, reasoning effort, tools with its DSML form, grammar and strict tools, images through `--vision dynamic`, a context of up to 1,048,576 tokens, one or two cards, `--parallel` slots, conversations parked in RAM and on disk, idle sleep and wake, `POST /v1/vram`, `basalt-probe` and the bench fixtures.
- **Not supported:** `--kv` (fp16 is the only cache format, so the flag is the normal unknown-argument error), the sidecar image modes, the `--rope-*` and `--yarn-*` flags, and the flags only Flash-Next has.
- **Quality:** `basalt-bench --quality` scores it against a BF16 reference of the model made by @giveen. At 400 W + 180 W, 100 chunks: KLD 0.278, top-1 83.88%, PPL 3.033 against the base's 2.731. [precision](../precision/deepseek41.md#against-the-bf16-reference)
- **Prompt skip:** in a long read, far rows stop at the compressor of layer 20, which is all a later token reads of them. It is on by default and `--no-prompt-skip` turns it off. Prompt skip and the read share change rounding, not math: from the last prompt token on the math is a full read's, and a run differs from a full read as another chunk size does. [prompt skip](../precision/deepseek41.md#prompt-skip)
- **Drafting:** the DSpark drafter runs by default when the pack carries it, in windows of 3 (`--spec 0` turns it off), and each
  stage keeps its 32 most routed experts (`--draft-experts`), 2.41 GiB instead of 7.47, by a ranking counted on live runs of the
  model and shipped in `data/profiles`. A pack without the section decodes plain with one log line. At 400 W + 180 W, greedy 800
  tokens: code 82.6 tok/s against 62.2 plain, a conversation 78.1 against 64.7, prose 69.6 against 65.2; a long agentic
  conversation at temperature 1, 63.15 against 62.15.

## The pack

- `convert.py --sections-from BASE` takes a deepseek41 pack's DSpark and vision sections from BASE, and its Engram table too when the shard holding it stops after its header, so a new pack that shares the table needs no second copy of it.
- `dspark/gguf` is a new optional section: `convert.py --dspark FILE --into PACK --undo-dir DIR` appends it without moving any other section, and `--roll-back` undoes it. No format version change: an engine that does not know the section ignores it. [model file](../model-file.md#deepseek-pack), [format changelog](../model-file.md)

## Recent

Changes since 0.2.1.

### New

- `basalt-bench --quality` scores DeepSeek-V4.1-Flash too, against its BF16 reference (reference by @giveen); each model names the flags and the window of its gate.
- The stats page's header is a model picker: choosing a model loads it, and the header shows the load's progress.
- `/health`, `/metrics` and `/v1/status` report swaps and each model; `/v1/models` lists every configured model with its status.
- `--lazy` keeps `--vision dynamic`, which encodes inside the engine a request loads first; only a sidecar encoder is dropped (@polygizer, D_remi).
- Images in tool results reach the prompt on every API; what cannot be placed is refused and logged.

### Fixed

- An engine line with broken UTF-8 no longer stops the server's reader thread.
- Grammar: a closing tag with non-ASCII characters parses.
- An idle sleep the engine refused warns once and waits for the next request.
- The first SIGTERM ignores later ones, so the engine's exit and its spill to disk are not cut short.
- `/metrics` reports the GPU on Windows: NVML is read from `nvml.dll` (@polygizer).

### Removed

- `basalt-overlap` and `basalt-concurrent`, and code nothing could reach, among it the naive S2 decode and S2 GEMV kernels and the verify window's S2 expert branch.
