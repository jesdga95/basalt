# PP 캐시 대여와 청크 크기

단일 GPU의 전문가 RAM 상주 모드에서, 프롬프트 버퍼가 덮어쓸 GPU 전문가 중 RAM 복사본이 없는 항목만 기존 동기화·메모리 할당 검사 경로로 보존한다. 원래 GPU 슬롯을 리필한 뒤 추가 RAM 홈을 해제한다. 다른 GPU 구성의 대여 조건은 유지한다.

초기 RAM 예산이 GPU 캐시 중복 복사본을 제외했다는 이유만으로 PP 청크를 축소하지 않는다. 가중치 형식과 CUDA 커널은 바뀌지 않지만, 청크 크기는 GEMM 타일 선택과 K/V 반올림에 영향을 줄 수 있다. 따라서 서로 다른 청크 크기 사이의 비트 단위 동일성을 가정하지 않는다.

실제 청크, 파일 blob 읽기, PP 시간, 출력 회귀, 장문 키 회수, 이미지, 메모리 결과를 검증한다. 기능 출력 검사와 Q8_0 참조 대비 PPL/KLD 품질 검증은 구별한다.
